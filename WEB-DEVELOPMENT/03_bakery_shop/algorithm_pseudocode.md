# Bakery and Cake Shop – Algorithm and Pseudocode

## Aim
Display bakery products, offers and contact details.

## Algorithm
1. Start.
2. Load the HTML page and CSS file.
3. Display the bakery name and navigation.
4. Display menu items and prices.
5. Display offers and contact information.
6. Apply CSS styling and responsive layout.
7. Test navigation and page layout.
8. Stop.

## Pseudocode
```text
BEGIN
LOAD bakery webpage
DISPLAY bakery name and navigation
DISPLAY products and prices
DISPLAY offers and contact details
APPLY CSS styling
END
```
